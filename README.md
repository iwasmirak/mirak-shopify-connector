# Mirak Connector for Shopify (Lite) — Odoo 19

Free connector between Odoo 19 (Community or Enterprise) and one Shopify store:
products and variants in both directions, images, stock of the main location, order import and fulfillments.

Setup guide: [mirak_shopify_connector/README.md](mirak_shopify_connector/README.md)
